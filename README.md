### Projects

**[AI Usage Analytics](https://github.com/krishnamittal1806/AI-Usage-Analytics)**
Distributed event-streaming platform. A producer service publishes AI usage events to Apache Kafka; a consumer service processes them downstream. Built with Java 21, Spring Boot, and Docker Compose. Core pipeline implemented — analytics persistence is in progress.

**[JobPilot](https://github.com/krishnamittal1806/jobpilot)**
Backend for job discovery and resume processing. Spring Boot 4, Spring Security, PostgreSQL with Flyway migrations, Redis caching, and Docker Compose. API structure and schema in place — AI integration is planned.

**[CSAO Recommendation System](https://github.com/krishnamittal1806/CSAO-Advanced-Recommendation-System-)**
Zomato hackathon project. Ranks top-5 cart add-on items using LightGBM to improve average order value. Built with Python, FastAPI, and Streamlit.

**[Portfolio](https://github.com/krishnamittal1806/Portfolio)** &nbsp;—&nbsp; [portfolio-krishnamittal.vercel.app](https://portfolio-krishnamittal.vercel.app)
Personal portfolio site. TypeScript, React, deployed on Vercel.
